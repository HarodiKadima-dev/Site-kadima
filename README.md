# 🛒 Kadima Services

> Plataforma de venda de equipamentos eletrónicos e serviços

## 📌 Sobre o projeto
Site para apresentação e comercialização de produtos como:
📱 Telemóveis  
💻 Computadores e acessórios  
📦 Outros artigos eletrónicos disponíveis

### ✨ Funcionalidades principais:
✅ Visualizar todos os produtos disponíveis  
✅ Adicionar produtos ao pedido  
✅ Sistema de **gestão de pedidos**  
✅ Página de **Contacto** — onde o utilizador pode:
   • Fazer pedidos específicos  
   • Enviar reclamações ou sugestões  

📱 Layout **responsivo**, funciona bem em telemóvel, tablet e computador.

## 🛠️ Tecnologias usadas
- ✅ **HTML5** — estrutura das páginas
- ✅ **CSS3** — estilo, cores e organização visual
- ✅ **JavaScript** — interação, lista de produtos e fluxo dos pedidos
